# قبولي v1.0 — المحرك الصحيح للحدود الدنيا 2025–2026

- اعتماد ملف الحدود الدنيا الحكومية 2025–2026.
- اعتماد دليل القبول الأهلي 2025–2026 الصحيح.
- ربط القسم الأهلي بحده الأدنى حسب الفرع والدراسة.
- الأقسام التي ينص الدليل على أنها تخضع للمفاضلة دون رقم لا يتم اختراع رقم لها، وتظهر كـ«مفاضلة» عندما يكون فرع الطالب ضمن مدخلات القسم.
- معدل الطالب الأقل من حد القسم لا يظهر: 59.99 لا يظهر لقسم حده 60.00، و60.00 يظهر.
- ربط المهني بتخصصه الفرعي.
- تنظيف «التربية السالمية» إلى «التربية الإسلامية» و«التربية البدنية وعلوم الرياضة» من أخطاء استخراج PDF.
- سجلات حكومية: 1222.
- سجلات أجور أهلية: 1356.

- إصلاح إضافي: الأقسام التي يصفها دليل 2025–2026 بأنها خاضعة للمفاضلة تظهر عندما يكون فرع الطالب ضمن مدخلاتها، مع وسم «مفاضلة» بدل حذفها من النتائج.


## v1.1 — تقسيم قاعدة البيانات
ملف البيانات لم يعد ملفًا واحدًا ضخمًا. قاعدة البيانات موزعة داخل `data/` في ملفات JSON صغيرة، ويقوم الموقع بتحميلها تلقائيًا من GitHub Pages.
