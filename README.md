# قبولي v0.7 — إصلاح ربط الفرع بالقسم

- تم إصلاح المشكلة التي كانت تعرض أقسامًا أهلية غير مناسبة للفرع المهني؛ مثل «التربية الفنية» أو «التصميم» لمجرد أن القسم موجود في دليل الأجور.
- أصبح اختيار «مهني» يتطلب اختيار التخصص: تجاري أو صناعي مع التخصص الفرعي.
- طبق الدليل 2025–2026 قواعد التجارة على أقسام مثل إدارة الأعمال والمحاسبة والعلوم المالية والمصرفية والاقتصاد، وقواعد الصناعة على الأقسام التي يذكرها صراحة.
- تم تطبيق قبول الفروع المهنية في أقسام الفنون والرياضة والتصميم والسياحة وغيرها فقط عندما يذكر دليل 2025–2026 ذلك.
- تم تنظيف أسماء الأقسام والكليات وملء اسم الكلية في صفوف الجداول المدمجة.
- عدد السجلات الحكومية: 1222.
- عدد سجلات الأجور الأهلية بعد التنظيف: 1329.
