- تصحيح أسماء الأقسام الشائعة مثل «التربية السالمية» → «التربية الإسلامية»، و«علوم الرياضة التربية البدنية و» → «التربية البدنية وعلوم الرياضة».
- النتائج لا تعتمد على «المفاضلة» كبديل عن الحد الأدنى.
- القاعدة الوحيدة لنتيجة البحث المعدلية: **معدل الطالب >= الحد الأدنى للقسم**.

- الأقسام التي يذكر الدليل أنها تخضع للمفاضلة دون رقم محدد لا يتم تخمين حد لها.
- الفرع المهني يبقى مرتبطًا بالتخصص الفرعي (تجاري/صناعي وتخصصه).
