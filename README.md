# قبولي v0.2
توسعة لنسخة 0.1 بالاعتماد على دليل القبول المركزي الحكومي ودليل الكليات الأهلية 2025–2026.
- توسعة كبيرة لبيانات التخصصات الحكومية من جداول الدليل.
- إضافة الكليات والمعاهد والتشكيلات التقنية مع الموقع.
- إظهار موقع الجامعة/الكلية/المعهد في كل نتيجة.
- إضافة إدخال أحيائي في الواجهة ومعاملته ضمن العلمي في هذه النسخة.
- فصل «مطابقة الفرع» عن «القبول النهائي التنافسي».
- إضافة عينة أهلية أوسع بالموقع والأجور الواردة في الدليل.
- عدد السجلات الحكومية المستخرجة آليًا: 934.
- إجمالي السجلات: 946.
