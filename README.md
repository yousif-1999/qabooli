# قبولي v0.3 — الحدود الدنيا الفعلية

- تم استبدال منطق الحكومي من «الفرع فقط» إلى مقارنة المعدل مع **الحد الأدنى الفعلي** في ملف الحدود الدنيا 2025–2026.
- عدد سجلات الحدود الدنيا الحكومية المستخرجة: 1222.
- كل نتيجة حكومية تحتوي على المؤسسة، التخصص، الموقع، الحد الأدنى، الفرع، الجنس، ورقم الصفحة المصدر.
- أضيفت بيانات أهلية مع الموقع والأجور لبعض الأقسام الواردة في دليل الجامعات والكليات الأهلية 2025–2026.
- الأهلية لا تعرض «قبولًا نهائيًا»؛ بل مطابقة للبيانات المدخلة، والقبول المركزي النهائي تنافسي.
