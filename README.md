# قبولي v0.5 — اعتماد دليل الأهلي 2025–2026

تم اعتماد الدليل الأهلي الجديد 2025–2026 كمصدر لقواعد القبول والحدود الدنيا ومدخلات الفروع.

المهم:
- تم إلغاء استخدام دليل 2024–2025 كمصدر لقواعد القبول.
- تم إبقاء بيانات الأجور من دليل الأجور الأهلي الذي كان مستخدمًا في النسخة السابقة، لأن الدليل الجديد المرفوع هنا يركز على شروط/حدود/مدخلات القبول ولا يعرض جدول الأجور الجامعي بنفس الصورة.
- الحكومي الصباحي: مجاني.
- الحكومي المسائي: يطبق الحد الأعلى للأجور الوارد في دليل القبول المركزي، بحسب فئة التخصص.
